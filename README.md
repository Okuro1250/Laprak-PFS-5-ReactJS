# React TodoList CRUD

Aplikasi TodoList sederhana menggunakan React JS 19 dan Bootstrap.

## Fitur Aplikasi

- Create: Menambahkan tugas.
- Read: Menampilkan daftar tugas.
- Update: Mengubah tugas.
- Delete: Menghapus tugas.
- Badge warna untuk prioritas tugas.
- Indikator status tugas.
- Tampilan responsif menggunakan Bootstrap.

## Cara Menjalankan Project

1. Clone repository.
2. Jalankan npm install.
3. Jalankan npm run dev.
4. Buka localhost yang muncul di terminal.
